Prototypes

Throwaway-but-kept design explorations for the site. Self-contained HTML, real data, real palette — no build step and no framework. Nothing in here is deployed: the Pages workflow only fires on nate-website/**, and this directory sits above it.

Blog redesign — five layouts

The current /blog rebuilt for comparison, then four alternatives: a typographic Stream, a level-first Ladder, a Constellation wired back to the EYNTKA books, and a Broadsheet using build-time PDF page renders as art. Real posts and real compile dates from the blog manifest.
